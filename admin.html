Logg inn

Admin-siden lagrer innleggene rett i GitHub, og Vercel publiserer dem automatisk. Den trenger en GitHub-nøkkel (token) én gang:

  1. Åpne github.com → Ny fine-grained token
  2. Navn: blogg-admin, utløp: velg f.eks. 1 år
  3. Repository access: Only select repositories → trigerogtiger.blogg.no
  4. Permissions → Repository permissions → Contents: Read and write
  5. Trykk Generate token, kopier og lim inn her

Nytt innlegg

Tom linje = nytt avsnitt. Teksten lagres som utkast mens du skriver.
